Hoạt động 1: "Object Identity" - Định danh đối tượng

Khai báo Object chứa thông tin bản thân (tên, tuổi, chuyên ngành, kỹ năng). Vận dụng phương thức nội tại (method) và từ khóa this để tự động tính năm sinh và in lời giới thiệu ra màn hình.

Kết quả cũng được in đồng thời vào Console thực tế của trình duyệt (Nhấn F12 > Tab Console để kiểm tra).

object_identity.js (Vibe Coding with AI) 
// 1. Khai báo Object User hoàn chỉnh
const user = {
  ten: "Huỳnh Hữu Phước",
  mssv: "125000155",
  tuoi: 20,
  chuyenNganh: "Công nghệ Thông tin",
  kyNang: ["HTML5", "CSS3", "JavaScript", "Responsive Design", "Git"],
  
  // 2. Phương thức tự tính năm sinh (Vibe Coding prompt)
  tinhNamSinh: function() {
    const namHienTai = new Date().getFullYear();
    return namHienTai - this.tuoi;
  },

  // 3. Phương thức tự giới thiệu bản thân
  gioiThieu: function() {
    return `Xin chào! Tôi là ${this.ten}, ${this.tuoi} tuổi (sinh năm ${this.tinhNamSinh()}), chuyên ngành ${this.chuyenNganh}. Kỹ năng: ${this.kyNang.join(', ')}.`;
  }
};

// Gọi phương thức và in kết quả:
console.log(user.gioiThieu());
console.log("Năm sinh tính được:", user.tinhNamSinh());
