Hoạt động 3: "Dynamic UI Render" - Đổ dữ liệu tự động

Kết hợp kiến thức DOM (Tuần 10) và duyệt mảng (Tuần 12) để tự động sinh ra hàng loạt thẻ giao diện từ mảng dữ liệu Objects. So sánh hiệu năng giữa map() + innerHTML và forEach() + createElement().

Phương pháp Render hiện tại:
Thời gian thực thi: 0.00 ms
Số thẻ được tạo: 0 thẻ
Thêm khóa học mới vào mảng dữ liệu (Data Drive UI)
Tự động cập nhật UI

Kết quả đổ dữ liệu tự động ra DOM:

Phương pháp: map()
Cách 1: map().join('') (Khuyên dùng) Clean & Fast 
// Tạo mảng chuỗi HTML và gán vào innerHTML 1 lần duy nhất
const html = courses.map(course => `
  <div class="card">
    <h4>${course.title}</h4>
    <p>GV: ${course.instructor}</p>
    <span>${formatVND(course.price)}</span>
  </div>
`).join('');

container.innerHTML = html;
Cách 2: forEach() + createElement() DOM Manipulation 
// Duyệt từng phần tử và tạo Element thủ công
container.innerHTML = '';
courses.forEach(course => {
  const card = document.createElement('div');
  card.className = 'card';
  card.innerHTML = `
    <h4>${course.title}</h4>
    <p>GV: ${course.instructor}</p>
    <span>${formatVND(course.price)}</span>
  `;
  container.appendChild(card);
});
