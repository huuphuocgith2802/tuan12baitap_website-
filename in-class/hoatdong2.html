Hoạt động 2: "The Product Filter" - Bộ lọc sản phẩm hiện đại

Sử dụng hàm Array.prototype.filter() để trích xuất tập con sản phẩm theo điều kiện và hàm Array.prototype.map() để trích xuất tên hoặc tạo cấu trúc HTML hiển thị ra màn hình.

Danh sách hiển thị: 10 sản phẩm

Tiêu chí: Tất cả sản phẩm
Console.log() Output của map & filter
filter_and_map_logic.js 
// 1. Mẫu dữ liệu 10 sản phẩm
const products = [
  { id: 1, ten: "Chuột Logitech M331", gia: 350000, onSale: true },
  { id: 2, ten: "Bàn phím cơ DareU EK87", gia: 550000, onSale: false },
  ...
];

// 2. Lọc sản phẩm đang giảm giá (Hoạt động 2)
const sanPhamGiamGia = products.filter(sp => sp.onSale === true);

// 3. Prompt mẫu: Lọc giá > 1 triệu & map in tên
const sanPhamDatTien = products.filter(sp => sp.gia > 1000000);
const tenSanPham = sanPhamDatTien.map(sp => sp.ten);
console.log("Tên các sản phẩm > 1 triệu:", tenSanPham);
