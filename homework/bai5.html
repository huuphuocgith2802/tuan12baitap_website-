Bài 5: Biến đổi mảng chuỗi thành thẻ HTML với map()

Sử dụng hàm Array.prototype.map() để chuyển đổi một mảng tên thông thường thành một mảng các phần tử HTML <li>Tên</li>, trực quan hóa quy trình pipeline dữ liệu từ Array thô đến giao diện.

Quy trình biến đổi dữ liệu (Data Transformation Pipeline)
map() 1-to-1 Mapping
Dữ liệu mẫu nhanh:
1. Mảng gốc (Input Array) 5 items 

          


          
          

            

               2. Mảng thẻ <li> (map result)
              String Array
            

            

          


          
          

            

               3. Render ra giao diện (DOM <ul>)
              Live DOM
            

            

              
    
                
              

            

          


        


      

    


    
    

      

        array_map_transformation.js (Mã nguồn thực hiện Bài 5)
        
      

      
// 1. Mảng danh sách tên ban đầu
const danhSachTen = ["Huỳnh Hữu Phước", "Nguyễn Văn An", "Trần Thị Mai Lan"];

// 2. Sử dụng map() để biến đổi từng tên thành thẻ <li>
// map() tạo ra một mảng mới có cùng độ dài, mỗi phần tử là giá trị trả về của hàm callback
const mangTheLi = danhSachTen.map(ten => `<li class="list-item">${ten}</li>`);

console.log("Mảng các thẻ li:", mangTheLi);
// Kết quả: ["<li class=\"list-item\">Huỳnh Hữu Phước</li>", ...]

// 3. Đổ ra giao diện bằng cách nối mảng thành chuỗi với join('')
const ulElement = document.getElementById('myList');
ulElement.innerHTML = mangTheLi.join('');
