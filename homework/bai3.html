Homework Exercise 03

Bài 3: Sắp xếp danh sách sản phẩm với sort()

Sử dụng hàm Array.prototype.sort() kết hợp hàm so sánh (comparator function) để sắp xếp danh sách sản phẩm theo giá tăng dần, giá giảm dần, và thứ tự bảng chữ cái A-Z.

Đang sắp xếp: Giá thấp đến cao
sort_comparator_logic.js 
// 1. Sắp xếp giá từ thấp đến cao (Ascending)
const theoGiaTangDan = [...products].sort((a, b) => a.gia - b.gia);

// 2. Sắp xếp giá từ cao đến thấp (Descending)
const theoGiaGiamDan = [...products].sort((a, b) => b.gia - a.gia);

// 3. Sắp xếp chuỗi chữ cái tiếng Việt với localeCompare()
const theoTenAZ = [...products].sort((a, b) => a.ten.localeCompare(b.ten, 'vi'));

console.log("Mảng sau khi sắp xếp giá tăng dần:", theoGiaTangDan);
Lưu ý quan trọng về hàm sort()
  • Làm biến đổi mảng gốc (In-place Mutation): Hàm sort() mặc định thay đổi trực tiếp mảng ban đầu. Vì vậy, luôn dùng cú pháp sao chép [...products].sort() để giữ nguyên dữ liệu gốc (Immutability).
  • Nguyên lý hàm so sánh:
    • Nếu (a - b) < 0: a đứng trước b.
    • Nếu (a - b) > 0: b đứng trước a.
    • Nếu (a - b) === 0: Giữ nguyên thứ tự.
  • Sắp xếp chuỗi tiếng Việt: Sử dụng a.ten.localeCompare(b.ten, 'vi') để hỗ trợ dấu thanh và các ký tự đặc biệt tiếng Việt chính xác.
