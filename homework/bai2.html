Bài 2: Tính tổng giỏ hàng (Shopping Cart Total)

Cho một mảng các sản phẩm trong giỏ hàng (tên, giá, số lượng). Sử dụng hàm Array.prototype.reduce() để tính lũy kế tổng số tiền và cập nhật trực tiếp theo thời gian thực khi thay đổi số lượng.

Sản phẩm trong giỏ hàng (0 món)
Tóm tắt đơn hàng
Tổng tiền hàng (Tạm tính): 0 ₫
Giảm giá voucher: -0 ₫
Thuế VAT (8%): 0 ₫
Tổng thanh toán: 0 ₫
cart_reduce_logic.js (Cách hoạt động của Array.prototype.reduce) 
// 1. Mảng các sản phẩm trong giỏ hàng
const gioHang = [
  { id: 1, ten: "Chuột Gaming Logitech G102", gia: 420000, soLuong: 2 },
  { id: 2, ten: "Bàn phím cơ AKKO 3087", gia: 1250000, soLuong: 1 },
  { id: 3, ten: "Lót chuột cỡ lớn RGB", gia: 180000, soLuong: 3 }
];

// 2. Tính tổng tiền bằng reduce()
// Cú pháp: array.reduce((accumulator, currentItem) => accumulator + ..., initialValue)
const tongTien = gioHang.reduce((accumulator, item) => {
  return accumulator + (item.gia * item.soLuong);
}, 0);

console.log("Tổng tiền giỏ hàng:", tongTien); // Kết quả: 2.630.000 ₫
