Bài 6: Xóa phần tử & Đồng bộ Dữ liệu với Giao diện

Xây dựng logic khi click vào nút "Xóa" cạnh sản phẩm, phần tử đó sẽ bị loại bỏ khỏi mảng dữ liệu bằng filter() hoặc splice(), đồng thời tự động cập nhật lại danh sách hiển thị trên DOM.

Còn lại: 0 sản phẩm
Phương pháp: Array.filter()
delete_logic.js (2 cách xóa phần tử trong mảng JS) 
// CÁCH 1: Dùng filter() (Khuyên dùng trong Functional Programming & React)
// Lọc giữ lại tất cả sản phẩm CÓ ID KHÁC với ID cần xóa
function xoaBangFilter(idCanXoa) {
  danhSach = danhSach.filter(sp => sp.id !== idCanXoa);
  renderDanhSach(); // Vẽ lại giao diện
}

// CÁCH 2: Dùng findIndex() kết hợp splice()
function xoaBangSplice(idCanXoa) {
  const index = danhSach.findIndex(sp => sp.id === idCanXoa);
  if (index !== -1) {
    danhSach.splice(index, 1); // Xóa 1 phần tử tại vị trí index
    renderDanhSach();
  }
}
So sánh 2 cách xóa
